💡 How to Find Your Delay:

  1. Start your RTMP stream from phone to OBS
  2. Add the overlay URL as a browser source in OBS
  3. While driving, do a hard brake
  4. Watch when the G-meter reacts vs. when you see it in the video
  5. If overlay is too fast → increase delay
  6. If overlay is too slow → decrease delay
  7. Adjust until perfectly synced!

Typical values: 360p local (800-1200ms), 360p network (1500-2000ms), 720p/1080p (2000-3000ms)
